# Design

Read [host adaptation](references/preview.md#host-adaptation) first. It maps the guides' tools and formats to this agent and ordinary project files.

For visual design and revisions, read the full [design guide](references/design/guide.md) and [design craft](references/design/references/craft.md). Follow the guide's routing to format, questions, annotations, components, diagrams, print, and conditional brand references.

For design-system creation, import, or updates, read the full [system guide](references/design-system/guide.md) and [system craft](references/design-system/references/craft.md). Follow its routing to format, covers, code sources, design-tool sources, and worked examples. Consuming an existing system does not require rebuilding it.

Follow the guides' complete methods. Apply the host adaptation to editor-specific examples, and read only the references required by the task.

In each guide directory, `SKILL.md` means its `guide.md`, and `references/…` means its own adjacent `references/`.

Continue work in the current agent conversation. The [static helper](references/preview.md#static-preview-helper) is available for new prototypes; existing applications keep their own framework and preview service.
